# Expense Tracker

Una aplicación web para registrar y controlar gastos personales de forma sencilla.

# Características actuales (V2)
- **CRUD Completo:** Crear, leer, actualizar (editar) y eliminar gastos.
- **Persistencia de datos:** Los gastos se guardan en el `localStorage` del navegador, por lo que no se pierden al recargar la página.
- **Cálculo automático:** Suma total de los gastos en tiempo real.
- **Diseño Responsive:** Adaptado para verse bien en computadoras y teléfonos móviles.
- **Validación de formularios:** Uso de validaciones nativas de HTML (`required`, `min`, `type="number"`).

# Tecnologías utilizadas
- **HTML5:** Estructura semántica.
- **CSS3:** Estilos, Flexbox, CSS Grid y Media Queries.
- **JavaScript (Vanilla):** Lógica de la aplicación, manipulación del DOM, eventos y manejo de estado.
